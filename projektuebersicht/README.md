# Projektübersicht für die Geschäftsführung

`index.html` (Bildschirm) und `Projektuebersicht-ViP.pdf` (A4, 5 Seiten):
Live-Übersetzer, Tarifberater und Jobticket-Rechner mit Problem, Lösung,
Stand, nächstem Schritt, Kosten/Datenschutz und vier Entscheidungsvorschlägen.

Die Bilder sind in die Datei eingebettet (Screenshots aus den Tests der
jeweiligen Projekte). Das PDF entsteht per Chromium-Druck aus `index.html`;
im Browser geht es auch mit Drucken → „Als PDF speichern“ (Hintergrundgrafiken
einschalten).
